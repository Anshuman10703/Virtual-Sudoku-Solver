# Virtual Sudoku Solver with Hand Gestures 🖐️

This Python project is an interactive Sudoku game that you can play without a mouse or keyboard. It uses your webcam to track your hand gestures, allowing you to select cells and input numbers in a completely virtual environment.

## ✨ Features

- **Gesture Control:** Uses a "point and hold" gesture with your index finger to select cells and numbers. No clicking needed!
- **Real-time Validation:** Instantly checks if a number is valid according to Sudoku rules.
- **Color-Coded Feedback:** Correctly placed numbers appear in **green**, while incorrect numbers appear in **red**.
- **On-Screen UI:** All elements, including the puzzle grid, number pad, and buttons, are rendered on the screen.
- **Multiple Puzzles:** Comes with 10 pre-loaded puzzles of varying difficulty.
